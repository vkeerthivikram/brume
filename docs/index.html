Frosted glass panels with backdrop-filter blur and cyan-tinted borders. Every surface looks like frozen glass.

From Snow (lightest) to Void (deepest). Each variant maintains the same frost-tinted color relationships.

Quick Start

Use Brume in any project — CSS custom properties, JSON, or copy hex values directly.

CSS Custom Properties

/* Link to a variant */
<link rel="stylesheet" href="ports/css/brume-mist.css">

/* Use in your styles */
.glass-panel {
  background: rgba(30, 50, 70, 0.35);
  backdrop-filter: blur(14px);
  border: 1px solid rgba(126, 200, 232, 0.12);
}

JSON Palette

import palette from './palette/colors.json';

const mist = palette.variants.mist.colors;
console.log(mist.ice); // #8ad0ea
